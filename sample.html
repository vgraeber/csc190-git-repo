What We Learned

To collaborate using Git and GitHub while implementing various tools:

Git Branches

  • Branches allows developers who are apart of a team to work independently without changing the main project immediately

Commits

  • Commits keep a record of changes made to the project making it easier to track progress

Pull Requests

  • Pull request allows developers to propose changes to the project before a merge

Merge Conflicts

  • Merge conflicts occur when Git encounters issues when combining changes.

Our Takeaways

  • Branches are great for handling individual work without disturbing the work of others!
  • Commits help build up the codebase bit by bit, allowing team members to work together at a managable pace!
  • In tandem with branches, pull requests are used to help combine changes together, streamlining the product's development!
  • However, merge conflicts may arise due to the naturally ocurring inconsistencies between branches!
